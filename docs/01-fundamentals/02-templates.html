02 · Templates: hablar con el DOM

Interpolación, property binding, event binding y two-way. Cuatro formas de conectar el estado con la plantilla, y cuándo usar cada una.

  • Proyecto: ch01-02-templates
  • Ruta: chapters/01-fundamentals/02-templates
  • Requiere: 01-hello-world
Objetivo de la clase

Interpolación, property binding, event binding y two-way. Sin formularios todavía: el two-way se practica con model(), no con ngModel.

1. Interpolación

Dobles llaves y una expresión de TypeScript. El resultado se convierte a string y se escapa: no puedes inyectar HTML por aquí. 

readonly nombre = signal('Ada');
readonly total = computed(() => this.precio() * this.cantidad());
<p>Hola, {{ nombre() }}</p>
<p>Total: {{ total() }} €</p>
<p>{{ total() > 100 ? 'Envío gratis' : 'Envío 4,95 €' }}</p>

Los signals se leen con paréntesis: nombre(), no nombre. Olvidar los paréntesis muestra la función en pantalla y no rompe el build.

2. Property binding

Corchetes: asignas una propiedad del DOM o un input de un componente hijo. A diferencia de la interpolación, el valor conserva su tipo. 

<button [disabled]="guardando()">Guardar</button>
<img [ngSrc]="foto().url" [width]="320" [height]="180" alt="" />
<input [value]="nombre()" />
<div [class.activo]="seleccionado()"></div>
<div [style.max-width.px]="ancho()"></div>
<button [attr.aria-label]="'Cerrar ' + titulo()">×</button>
Sintaxis Cuándo
[prop] Propiedad del elemento o input de componente. Es lo normal.
[attr.x] Atributo HTML sin propiedad equivalente (aria-*, colspan).
[class.x] / [style.x] Clases y estilos. Sustituyen a ngClass y ngStyle, que aquí están prohibidos.

[src] directo en <img> compila, pero pierdes la optimización de NgOptimizedImage. Para imágenes estáticas usa ngSrc con width y height.

3. Event binding

Paréntesis: escuchas un evento del DOM o un output() de un hijo.

<button (click)="guardar()">Guardar</button>
<input (keyup.enter)="buscar()" />
<form (submit)="enviar($event)"></form>
readonly texto = signal('');

alEscribir(event: Event): void {
  const input = event.target as HTMLInputElement;
  this.texto.set(input.value);
}

$event está tipado como el evento concreto cuando Angular lo conoce (MouseEvent en click). Aun así, event.target es EventTarget | null: cast o comprobación explícita, nunca any.

4. Two-way binding

[(x)] es azúcar de [x] + (xChange). En un componente hijo se declara con model(): 

// campo.ts
import { Component, model } from '@angular/core';

@Component({
  selector: 'app-campo',
  template: `<input [value]="valor()" (input)="alEscribir($event)" />`,
})
export class Campo {
  readonly valor = model('');

  protected alEscribir(event: Event): void {
    this.valor.set((event.target as HTMLInputElement).value);
  }
}
<!-- padre -->
<app-campo [(valor)]="nombre" />

model() crea un signal escribible y el output valorChange a la vez. Si solo necesitas leer, input(); si solo emitir, output().

[(ngModel)] existe pero requiere FormsModule y aquí no se usa: los formularios nuevos van con Signal Forms (@angular/forms/signals) o, como mínimo, Reactive Forms. Nunca template-driven.

5. @let: constantes de plantilla

@let precio = producto().precio;
@let conIva = precio * 1.21;

<p>{{ conIva | currency: 'EUR' }}</p>

Evita repetir expresiones largas tres veces en la misma plantilla. Se recalcula cuando cambia lo que lee, y no existe fuera de su bloque.

6. Ejercicio

  1. Crea un componente tarjeta-producto con inputs nombre, precio y stock, y muéstralos con interpolación.
  2. Añade un botón Comprar con [disabled]="stock() === 0" y otro estado que cambie la clase del contenedor con [class.agotado].
  3. Crea un app-campo con model() y úsalo con [(valor)] desde el padre. Comprueba que el padre se actualiza al escribir.
  4. Pinta un contador de caracteres con {{ valor().length }} y comprueba que se refresca sin NgModel ni FormsModule.
  5. Cambia el [src] de una imagen por ngSrc y mira qué te exige el compilador.

Checklist de cierre

  • Build y prettier limpios.
  • No hay ngClass, ngStyle ni CommonModule importados.
  • Los eventos están tipados sin any.
  • El two-way funciona con model(), no con ngModel.
