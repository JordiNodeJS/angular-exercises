04 · Pipes y directivas de atributo

Formatear sin ensuciar el componente y añadir comportamiento a un elemento existente sin crear un componente nuevo.

  • Proyecto: ch01-04-pipes
  • Ruta: chapters/01-fundamentals/04-pipes
  • Requiere: 02-templates
Objetivo de la clase

date, currency, async y una directiva de atributo propia. Además: cuándo un pipe es una mala idea.

1. Pipes incluidos

Se importan sueltos desde @angular/common, nunca vía CommonModule. 

import { CurrencyPipe, DatePipe, DecimalPipe } from '@angular/common';

@Component({
  imports: [CurrencyPipe, DatePipe, DecimalPipe],
  /* ... */
})
{{ fecha() | date: 'dd/MM/yyyy' }}
{{ precio() | currency: 'EUR' : 'symbol' : '1.2-2' }}
{{ ratio() | number: '1.1-2' }}
{{ titulo() | titlecase }}
{{ textoLargo() | slice: 0 : 80 }}
Pipe Nota
date Acepta Date, número (ms) o string ISO.
currency Depende del locale activo. Por defecto, en-US.
decimal El formato 1.2-2 es «mínimo 1 entero, 2 decimales».
json Solo para depurar. Fuera del código final.

Locale en español

// app.config.ts
import { registerLocaleData } from '@angular/common';
import localeEs from '@angular/common/locales/es';

registerLocaleData(localeEs);

export const appConfig: ApplicationConfig = {
  providers: [{ provide: LOCALE_ID, useValue: 'es-ES' }],
};

Sin esto, currency: 'EUR' escribe €1,234.50 en vez de 1.234,50 €. El import del locale pesa: solo se añade cuando el ejercicio lo necesita.

2. async: el pipe que casi no hace falta

{{ usuarios$ | async }}

Se suscribe, entrega el último valor y se desuscribe al destruir el componente. Sigue siendo válido, pero en este repo el estado se modela con signals: si el dato llega como Observable, conviértelo en el borde con toSignal() y usa @if / @for en la plantilla. 

readonly usuarios = toSignal(this.http.get<Usuario[]>('/api/usuarios'), {
  initialValue: [] as Usuario[],
});

3. Un pipe propio

import { Pipe, PipeTransform } from '@angular/core';

@Pipe({ name: 'truncar' })
export class TruncarPipe implements PipeTransform {
  transform(valor: string, max = 40): string {
    return valor.length > max ? `${valor.slice(0, max).trimEnd()}…` : valor;
  }
}
{{ descripcion() | truncar: 60 }}

Los pipes son puros por defecto: solo se recalculan si cambia la referencia de entrada. Si el pipe recibe un objeto que mutas, no se refresca. Y no pongas una llamada HTTP dentro de un pipe: se ejecutaría en cada ciclo de detección.

4. Directivas de atributo

Una directiva es un componente sin plantilla: cambia el elemento donde se aplica. Se declara con @Directive, input() para parámetros y host para tocar el elemento. Prohibido @HostBinding / @HostListener. 

import { Directive, input } from '@angular/core';

@Directive({
  selector: '[appResaltar]',
  host: {
    '[style.backgroundColor]': 'color()',
    '(mouseenter)': 'activo.set(true)',
    '(mouseleave)': 'activo.set(false)',
    '[class.resaltado]': 'activo()',
  },
})
export class ResaltarDirective {
  readonly color = input('khaki', { alias: 'appResaltar' });
  protected readonly activo = signal(false);
}
<p appResaltar="lightblue">Pasa el ratón</p>

El alias permite escribir appResaltar="lightblue" en vez de [appResaltar]="..." con otro input. Si la directiva no se importa en el componente, el atributo se ignora en silencio.

5. Pipes frente a computed

Situación Herramienta
Formato de presentación (fecha, moneda, número) Pipe
Transformación de datos con lógica de negocio computed() en el componente
Mismo formato repetido en 5 plantillas Pipe propio
Filtrar u ordenar una lista computed(), no pipe

6. Ejercicio

  1. Configura el locale es-ES y muestra un precio con currency y una fecha con date. Comprueba antes y después del cambio.
  2. Crea el pipe truncar con un segundo parámetro opcional y úsalo en una tarjeta.
  3. Crea una directiva appResaltar con color por input y estado hover aplicado con host.
  4. Aplica la directiva a tres elementos con colores distintos y comprueba que no necesita @HostListener.
  5. Cambia un computed() que formateaba a mano por el pipe equivalente, y al contrario: mueve un filtro de un pipe (si lo has escrito) a computed().

Checklist de cierre

  • Build y prettier limpios.
  • Ningún CommonModule: solo los pipes que se usan.
  • La directiva usa host, no decoradores de host.
  • Ningún pipe hace peticiones ni muta estado.
