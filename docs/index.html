Angular 22 · pnpm

Clases de Angular

Una clase por ejercicio del roadmap. Cada HTML se abre en el navegador, sin build ni servidor: es material de lectura para seguir mientras trabajas en su app de chapters/.

Antes de empezar

pnpm install y un ejercicio generado. Los comandos usan pnpm exec; nunca npm ni yarn. El estado real de cada ejercicio vive en el README y en Notion, no aquí.

Cómo seguir una clase

  1. Lee la clase completa antes de tocar código: son cortas y el orden importa.
  2. Abre la app del ejercicio y sírvela: pnpm exec ng serve ch01-01-hello-world.
  3. Haz el bloque Ejercicio de la clase. Si algo no compila, el error es la lección.
  4. Cierra con el checklist: pnpm exec ng build <proyecto> y pnpm exec prettier --check <rutas>.
  5. Marca el avance en el README y en Notion (fila de Roadmap Angular).
