Capítulo 03 · Routing & Forms

01 · Router: rutas, parámetros y redirecciones

Una app con varias pantallas y una URL que las describe. Sin NgModules: rutas en un array y provideRouter.

  • Proyecto: ch03-01-router
  • Ruta: chapters/03-routing-forms/01-router
  • Requiere: capítulo 02
Objetivo de la clase

Rutas, parámetros, routerLink y redirecciones. Al terminar, la URL manda sobre la vista y los parámetros llegan al componente como inputs.

1. Configurar el router

// app.routes.ts
import { Routes } from '@angular/router';

export const routes: Routes = [
  { path: '', redirectTo: 'inicio', pathMatch: 'full' },
  { path: 'inicio', component: Inicio },
  { path: 'productos', component: Productos },
  { path: 'productos/:id', component: ProductoDetalle },
  { path: '**', component: NoEncontrado },
];
// app.config.ts
providers: [provideRouter(routes, withComponentInputBinding())];

withComponentInputBinding() hace que :id llegue como input(). Es la forma recomendada: el componente no necesita ActivatedRoute para leer parámetros.

2. El outlet y los enlaces

<nav>
  <a routerLink="/inicio" routerLinkActive="activo">Inicio</a>
  <a routerLink="/productos" routerLinkActive="activo">Productos</a>
</nav>

<router-outlet />
  • routerLink en vez de href: no recarga la página.
  • routerLinkActive añade la clase cuando la ruta está activa.
  • Para una coincidencia exacta: [routerLinkActiveOptions]="{ exact: true }".

3. Parámetros

// producto-detalle.ts
export class ProductoDetalle {
  readonly id = input.required<string>();
}
<a [routerLink]="['/productos', producto.id]">{{ producto.nombre }}</a>

El input se actualiza si navegas de /productos/1 a /productos/2 sin salir del componente. Con ActivatedRoute.snapshot ese cambio se te escaparía.

4. Navegar desde código

private readonly router = inject(Router);

irAlDetalle(id: string): void {
  this.router.navigate(['/productos', id]);
}

Para el caso normal, un routerLink es mejor: es accesible, soporta abrir en pestaña nueva y no depende de código.

5. Redirecciones y comodín

Ruta Efecto
'' + pathMatch: 'full' Redirige solo la URL vacía. Sin full, todo empieza por ''.
'**' Comodín. Debe ir la última.
redirectTo: 'inicio' Cambia la URL en el navegador, no solo la vista.

El orden importa: el router gana con la primera ruta que encaja. Una ruta con comodín antes de las demás se come la app y no da error.

6. Ejercicio

  1. Crea tres rutas: inicio, lista y detalle con :id. Comodín a una 404.
  2. Añade withComponentInputBinding() y lee el id con input.required<string>().
  3. Navega del detalle 1 al 2 sin volver a la lista y comprueba que el componente se actualiza (o se recrea, si el input cambia de ruta).
  4. Marca el enlace activo con routerLinkActive y estilízalo con un binding de clase.
  5. Escribe a mano /no-existe en la barra de direcciones y comprueba que la 404 sale sin recargar.

Checklist de cierre

  • pnpm exec ng serve ch03-01-router arranca y navega sin errores en consola.
  • Build y prettier limpios.
  • Ningún href interno: todo routerLink.
  • La ruta comodín está al final y la redirección tiene pathMatch.
